Projects

PHP LOGIN SYSTEM

This project is a secure user authentication system built with PHP and MySQL. It allows users to sign up for an account, log in with their credentials, and securely access protected pages. The system validates user input, manages sessions, and protects data stored in the database. Key features include: User registration with unique username and password. Password encryption for security. Session management to keep users logged in. Error handling for invalid credentials. A simple and responsive interface built with HTML & CSS. This project demonstrates my ability to build backend functionality with PHP, connect it to a MySQL database, and integrate it with a front-end user interface.

HTML AND CSS

This project is a static website built entirely with HTML and CSS. It focuses on clean structure, responsive design, and modern styling without relying on JavaScript or external frameworks. Key highlights: Organized layout using semantic HTML. Custom styling with CSS for typography, colors, and layout. Responsive design that adapts to mobile and desktop screens. Simple, lightweight, and fast-loading pages. This project demonstrates my ability to create professional web designs using only front-end fundamentals, making it a strong foundation for more advanced projects.
